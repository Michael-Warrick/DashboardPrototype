About

This project aims to provide Xenia with a more familiar and user friendly interface. Games, Social needs and Settings will all be available through a modern, customisable and gpu-driven interface instead of using configuration files.

Setup

To get started clone or download the project.

$ git clone --recursive https://github.com/Michael-Warrick/DashboardPrototype.git

Building

The project uses CMake and is by nature cross-platform, use the steps below to build and run.

$ cd DashboardPrototype
$ mkdir build && cd build
$ cmake ..
$ cmake --build .
